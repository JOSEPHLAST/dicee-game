# DICEE GAME 🎲

A simple interactive dice game where two players roll dice, and the player with the highest number wins!

## FEATURES
✅ Two-player dice roll simulation.   
✅ Randomized dice results using JavaScript.   
✅ Automatic winner detection.   
✅ Works directly in the browser—no installation required.   

## LIVE DEMO
[🚀 Live Preview](https://josephlast.github.io/dicee-game/)

## TECHNOLOGIES USED
	•	HTML – Structure of the game.
	•	CSS – Styling and layout.
	•	JAVASCRIPT – Handles dice roll logic and updates UI dynamically.

## INSTALLATION & USAGE
	1.	Clone the Repository:

git clone https://github.com/JOSEPHLAST/dicee-game.git   
cd dicee-game   

	2.	Open index.html in a browser (Chrome recommended).
	3.	Click the refresh button or reload the page to roll the dice!
